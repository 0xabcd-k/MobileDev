一款移动编程软件，以适应当代Vibe编程的开发模式

目标：
软件分为agent代理、server中继服务器、client客户端
1. 用户在拥有公网ip的服务器中部署server，并配置密码，启动。
2. 在自己的个人电脑之类的编程环境部署agent，配置相同的密码和server的公网ip，启动。
3. 在自己的移动设备上打开client客户端app，入口页配置相同的密码和server的公网ip。
4. 配置完成入口页显示可以访问的agent列表，也就是刚才连接到server的那些agent。
5. 点击其中一个agent，进入agent首页。可以查看这个agent已经安装的功能插件，点击安装好的功能插件就可以进入对应的功能。
6. 可以通过下载链接导入更多功能插件。

软件架构：
### server中继服务器
1. 生成自签名证书用于https服务
2. 密码配置，用于判断可信client、agent
3. agent、client通过密码可以与server建立wss连接
4. client可以通过server接口查询agent列表
5. client可以通过wss消息中指定agent id 将数据传输给指定的agent
6. agent可以通过wss消息中指定client id将数据传输给指定client

### agent代理
1. 启动后按配置连接server
2. 安装的功能插件都以文件夹的形式放在指定目录下
3. 提供列举已安装功能插件的方法
4. 提供安装新功能插件的方法
5. 通过标准输入输出和命令式的方式从插件中获取数据
6. 提供删除这个功能插件的目录的方法
7. 按照server转发来的client命令执行方法

### client客户端
1. 访问server获取agent列表
2. 进入agent页面，访问server获取已安装插件列表
3. 点击导入插件，向server发送安装命令
4. 点击插件，向server发送获取插件前端端点链接的命令
5. 插件前端可以通过app提供能力向自己的agent侧插件发送和接受消息

### plugin插件自身需实现的规范
1. 插件可以用任何语言编写，只要是agent所在环境可以运行的可执行程序即可
2. 插件需要能够处理如下命令 --health 查询是否健康 --do 执行指令，agent会持续转发输入和输出直到命令运行结束 --domain 获取前端连接端点
3. plugin的前端为在线网页，agent侧只是告诉网页地址
技术选型：
client用flutter开发
agent、server都用go语言开发
